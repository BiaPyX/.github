### Open-source tools for bioimage analysis

## 🔬 About

**BiaPyX** is an open-source software ecosystem focused on making advanced computational methods for bioimage analysis more accessible to researchers.

We develop tools that bridge computer vision, deep learning, and biological imaging, with an emphasis on flexible workflows, reproducibility, and practical usability. Our projects aim to help researchers move from microscopy images to meaningful quantitative results, without requiring everyone to become a machine-learning expert.

Our ecosystem includes computational frameworks, graphical interfaces, imaging-software integrations, and resources for deploying and using deep-learning models in bioimage analysis.

## 🚀 Our projects

| Project | Description |
|---|---|
| 🧠 **[BiaPy](https://github.com/BiaPyX/BiaPy)** | An open-source Python framework for deep-learning-based bioimage analysis. Supports workflows including semantic and instance segmentation, object detection, denoising, super-resolution, classification, self-supervised learning, and more, in 2D and 3D. |
| 🖥️ **[BiaPy-GUI](https://github.com/BiaPyX/BiaPy-GUI)** | A graphical interface designed to make BiaPy workflows accessible without requiring users to interact directly with the command line. |
| 📚 **[BiaPy-doc](https://github.com/BiaPyX/BiaPy-doc)** | Documentation, tutorials, and guides to help users get started and make the most of the BiaPy ecosystem. |
| 🧬 **[BiaPy-bioimage-io](https://github.com/BiaPyX/BiaPy-bioimage-io)** | Resources and integrations connecting BiaPy with the BioImage.IO ecosystem and deep-learning models for bioimage analysis. |
| 🔗 **[BiaPy-Fiji](https://github.com/BiaPyX/BiaPy-Fiji)** | Integration of BiaPy workflows into Fiji, bringing deep-learning-based image analysis closer to established microscopy workflows. |

Explore all our repositories on [GitHub](https://github.com/BiaPyX).

## 🧪 Applications

Our tools are designed to support a wide range of bioimage analysis tasks, including:

- **Segmentation** — Semantic and instance segmentation of biological structures.
- **Object detection** — Detecting and localising objects in microscopy images.
- **Image restoration** — Denoising and image super-resolution.
- **Image classification** — Image- and object-level classification.
- **Self-supervised learning** — Learning useful representations from images without manually annotated training data.
- **2D and 3D analysis** — Workflows for a wide variety of image dimensions, modalities, and biological applications.
